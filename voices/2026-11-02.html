长期 agent 的核心问题不是“记得更多”，而是“能否被正确遗忘”

本期 X 抓取未产生本地候选缓存；观点仅采用可核验的官方产品立场，并明确其限制。

作者：GitHub · 核心观点

GitHub 认为会话记忆与持续改进能让 agent 更贴合个人与仓库上下文，且个人偏好可以被查看或删除。

为什么值得看：它把“上下文质量”从提示词技巧提升为可管理的产品能力。
争议或限制：观察到的预览期改善不等于因果承诺；团队记忆的来源污染、过期和越权仍需单独治理。
如何使用：普通人可定期检查并删除不再适用的偏好；开发者应为记忆变更设审查、版本、过期时间和回归集。
