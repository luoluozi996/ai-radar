GitHub 将告警分配给 Copilot 后，agent 会探索代码、提出修复、重跑 CodeQL 并开草稿 PR；它仍应是人工审查前的候选方案。

关键事件 · Agentic autofix for code scanning alerts

GitHub 于 10 月 15 日宣布 agentic autofix 正式可用。它会跨代码库查找相关文件、生成修复、重跑 CodeQL 验证告警关闭，再生成待审草稿 PR；可一次处理最多 25 个默认分支告警。

为什么重要：“生成修复”从单个建议变为一条有验证记录的 agent 工作流，同时引入企业管理员策略、Copilot 计费方式、AI Credits 与 Actions 分钟数等治理面。

行动项：先限定告警类别和仓库，要求 PR 说明验证步骤；评审修复是否引入行为回归，设置预算，并保留人工批准与回滚。

边界：只支持默认分支的 code-scanning alerts，企业管理员须先在 Advanced Security policy 中启用。
