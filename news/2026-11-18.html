代码审查的“自适应努力”与 secret detection 同日上线

GitHub 表示 Copilot code review 增加按变更匹配审查深度的 Adaptive effort，并把秘密检测纳入审查路径。它的价值是把常规改动的速度与高风险变更的检查分层，而非让 agent 自动拥有合并权。

行动项：先用受保护分支、CODEOWNERS 和阻断规则定义“发现后谁负责”；统计误报、漏报、采纳率与修复时延，再逐步扩大范围。
