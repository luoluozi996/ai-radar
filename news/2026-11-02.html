GitHub 说明 agent 记忆的管理面：收益需要可控的上下文生命周期

官方将会话记忆和持续改进放入 Copilot 的产品能力描述，也明确提到用户可查看或删除个人偏好。

GitHub intelligence：代码、上下文与历史的持续利用

GitHub 的公开发布介绍 Copilot 会在会话中生成和整理记忆，并提出持续改进上下文的机制。该方向的价值在于减少重复说明和提升长期任务一致性，但它也让记忆范围、保留期和变更责任成为工程配置的一部分。

行动项：把可写入的记忆源限制为审查过的仓库规则和明确偏好；为团队设定删除、复核和回退流程，并用固定任务集测量质量改善，而不是只看主观体验。

限制：发布中提及的提升来自预览期观察，不能直接外推到所有仓库、语言或任务；记忆机制不替代权限、代码审查和测试。
