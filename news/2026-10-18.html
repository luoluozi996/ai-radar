Copilot 模型将在 11 月迁移：今天就把依赖写进配置清单

GitHub 公告称 Claude Opus 4.8、Claude Opus 5 与 GPT-5.6 Terra 将于 2026-11-16 在多数 Copilot 体验中退役，并给出替代建议。

关键事件 · GitHub Copilot selected-model deprecation

GitHub 将在 11 月 16 日移除部分 Copilot 模型：Claude Opus 4.8 和 Claude Opus 5 的建议替代为 Claude Opus 5.5；GPT-5.6 Terra 的建议替代为 GPT-6.1 Sol 或 GPT-6 Luna。年付个人订阅的 Opus 4.8 有特别例外。

为什么重要：模型选择若被写死在提示、自动化或评测脚本中，会在某一天变成运行故障；建议替代不等于输出、成本、延迟或安全表现完全等价。

行动项：导出仓库、CI、Copilot 配置和文档中的模型标识；为替代模型跑固定任务集的质量/时延/权限回归，并确认企业策略中已启用目标模型。

边界：公告覆盖 Copilot 体验，不能外推到其他供应商或 API 的模型可用性；管理员关闭全局默认启用时需单独调整策略。
