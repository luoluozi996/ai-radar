GitHub Agentic Workflows 正式可用

GitHub Agentic Workflows 可用 Markdown 定义自动化，再编译为标准 GitHub Actions YAML，用于 issue 分流、CI 失败分析、文档更新和测试编写等任务。它可复用既有 runner 组与策略，也支持 Copilot 或自带编码 agent。

行动项：从只读、低风险工作流开始；为触发条件、权限、预算、输出验证和人工批准建立版本化规则，再逐步扩大写入权限。

限制：官方列出的隔离、完整性过滤与安全输出机制降低风险，却不能代替针对仓库秘密、依赖和发布权限的审查；生产收益需以自身指标复核。
