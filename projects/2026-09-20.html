GitHub Copilot code review · 可追溯审查工作流

GitHub 的最新改进把 AI 审查从单次评论推进为可跟踪的过程：未解决、上次复审后已解决、以及后续才发现的问题都会被归类；批量采纳建议还能生成提交说明。

如何使用：将 Copilot 审查用于发现与分流，要求高风险改动关联测试、责任人与处理理由；在受保护分支上仍以人工审批为准。

限制：状态变化不等于根因正确，也不能替代权限控制、威胁建模与代码所有者审阅。
