从报错到可审查修复：把生产诊断带进 agent 工作流

GitHub Copilot app 新增 Sentry canvas：开发者可查看崩溃、堆栈与相关上下文，再让 Copilot 协助调查、验证修复并准备 PR。它把“异常信号”与“修复操作”接在一起，但并不能替代生产权限隔离和人工审批。

GitHub Copilot app · Sentry canvas

该集成把 Sentry 错误报告、堆栈和关联上下文带入 Copilot app 的画布，支持从问题排查到修复验证、PR 准备的连续工作流。

怎么用：先为只读诊断与写入代码分开授权；为每次修复保留错误链接、复现步骤、测试证据与回滚条件，再由代码所有者审阅。

限制：上下文充分不等于根因正确；Sentry 数据可能含敏感字段，接入前须执行脱敏与访问控制。
