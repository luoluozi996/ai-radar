GitHub Code Scanning · AI Scan for pull requests

GitHub 于 10 月 15 日宣布 AI Scan for pull requests 正式可用。启用代码扫描及仓库有效设置后，它会自动分析 PR 变更，补充 CodeQL 尚未覆盖的语言或框架，例如 PHP、Shell/Bash、Terraform、Dockerfile、JSP 与 Blazor。

如何使用：从一小组高风险仓库开始，给告警建立“有效、误报、人工修复成本”三项记录；再观察 AI Scan 与 CodeQL 的重叠率，按仓库扩大范围。

限制：发现项仅供参考，不能作为规则集的合并阻断条件；不会扫描 fork 或 Dependabot 创建的 PR。私有/内部仓库还需要相应安全产品，并消耗 Code Security AI Credits。
