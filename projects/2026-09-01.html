插件化与组织级 agent 配置进入日常工程

本期只保留可从官方说明复核的工作流信号。

GitHub Copilot · 组织级自定义 agents

Visual Studio 的八月更新说明组织和企业所有者可发布跨仓库的自定义 agent；团队可把常用规则与角色集中分发。

怎么用：先用一个只读或低风险仓库验证 agent 指令、权限边界与审计记录，再推广到组织范围。

官方发布
Agent Plugins 1.0

插件将能力、权限和版本作为可审查的交付单元，适合把团队工具链从“提示词约定”转为可复现配置。

限制：插件标准化不等于供应链安全；仍需审查来源、最小权限和版本锁定。
