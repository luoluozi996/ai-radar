把“模型替换”当成工具链迁移

今天的工程信号不是单一的新模型，而是 Copilot 的新模型上架与旧模型弃用同时发生。

GitHub Copilot · Gemini 3.8 Flash 可用

GitHub 已将 Gemini 3.8 Flash 放入 Copilot 的模型选择器，覆盖 VS Code、CLI、cloud agent、Copilot app 等入口；企业管理员可用模型策略管理访问。

怎么用：用一组真实的终端型编码任务比较质量、耗时、失败恢复与费用，再决定是否加入团队推荐列表。

限制：公告称为逐步推出，组织策略和计划类型会影响实际可见性；不能只凭“新”就替换生产默认值。

官方发布
GitHub Copilot · 模型弃用清单

GitHub 公告称 Gemini 3.5/3.6 Flash、Kimi K2.7 Code 与 Claude Opus 4.7 将在 10 月 2 日从 Copilot 体验中弃用，并给出替代模型。

怎么用：扫描 IDE 配置、CLI 脚本、CI、团队提示词和文档中的模型 ID；给每个替换项安排回归基准与回滚方案。

限制：替代名称不代表任务表现完全等价，尤其要重测工具调用、长上下文和成本上限。
