Copilot Evals：把 agent 迭代变成可回归的工程测试

提示、模型、skills 与工具变了，先用真实任务证据确认能力是否仍在。

GitHub Copilot Evals 公测：把 agent 的提示、工具和模型变化拉回可比较的评测

GitHub 发布 Copilot Evals 公共预览，用来检查 prompts、模型、skills 与工具变化后，agent 是否仍按预期工作。它把“感觉变好/变差”的讨论转成可复现的通过与失败证据。

如何使用：为高频任务建立小而稳定的回归集；记录期望工具调用、关键产物和人工判定；把模型、提示词、MCP/skill 更新都跑一遍。

限制：评测集只覆盖被写出的任务，容易被过拟合；仍要保留线上抽样、权限边界和成本/延迟指标。
