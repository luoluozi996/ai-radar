SDK 的新接口，应先落到边界清晰的试点

官方 openai-node 7.15.0 新增 Agents API；7.14.0 同日加入 Live API。它们给开发者的信号不是立即迁移全部工作流，而是把接口、权限与失败处理一起验证。

openai-node v7.15.0 · Agents API

官方 JavaScript/TypeScript SDK 发布记录列出 Agents API 支持，可作为已有 Node 服务接入新能力的稳定版本锚点。

怎么用：在隔离项目用最小工具集跑通一个任务，记录输入、工具调用、超时与人工接管。

限制：SDK 新增接口不等于业务权限已配置；实际可用能力仍以账户、服务端策略与版本文档为准。

官方 release
Live API · 同日 SDK 更新

实时接口进入同一版本序列，适合把语音或事件驱动体验与 agent 流程分开评估。

怎么用：先单独压测连接恢复、速率限制与日志脱敏，再决定是否接入生产业务。

限制：不应把演示中的实时体验直接等同于端到端可靠性。

官方 release
